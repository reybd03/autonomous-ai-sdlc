# Issue Tracking & Standards

This project uses **bd (beads)** by default for issue tracking.

Alternatively, projects may use **Agent OS v3** for standards and spec shaping (standards in `agent-os/standards/`, product docs in `agent-os/product/`, commands: `/discover-standards`, `/inject-standards`, `/index-standards`, `/plan-product`, `/shape-spec`). When using Agent OS, consult relevant standards before editing code and prefer updating standards via `/discover-standards`.
