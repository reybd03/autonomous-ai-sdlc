# Code Standards

- **Mandatory**: Every Project requires a High Level Design markdown document (`*_HLD.md`), with an Architecture Overview. No project may proceed to implementation without an approved HLD.
- **Mandatory prerequisite**: A Project Analysis (`*_Project_Analysis.md`) must be created and approved before an HLD can be drafted. Project Analysis sits at project inception and determines whether the project proceeds, defers, pivots, or declines.
- Every Epic requires a Low Level Design markdown document (between HLD and Feature Design)
- Every Project requires a Test Plan Design markdown document
- Every Feature and Bug issue will require a design document
- Every Test Plan requires a Test Case Specification
- HLDs and Test Plans must be filled in through constant communication between the User and the AI model, section by section, confirming each section before proceeding to the next
